                          INTERNATIONAL COVERAGE
                          Local charts & NOTAMs
                          FP does not integrate State chart products or operational international NOTAM feeds; external resources are not cached by FP. AIP:Aero indexes official chart links for 64 countries and supports direct airport pages for listed countries; some airports may be absent, so use the general index if a direct page is missing. Coverage varies, so verify each chart against the current State AIP. OpenFlightMaps publishes community-maintained VFR map data for selected regions only; it is not a worldwide service or a certified navigation source. Use your destination State's AIS/AIP for current NOTAMs. ICAO's global portal is collected every 12 hours and is reference-only; EAD Basic is not connected to operational NOTAM data.
